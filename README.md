# CLA commitments

For any repository that is part of the W3C Open Source Program, W3C must have on file a record from each Contributor indicating agreement with terms of the [W3C Open Source Individual Contributor License Agreement](https://www.w3.org/2026/07/w3c-open-source-icla.html) ("CLA"). This repository collects these agreements.

People willing to contribute to a project are invited to create a pull request in the repository of the project they want to contribute to, and follow the instructions they should see once the pull request is created.
